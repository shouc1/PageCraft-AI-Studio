# 正向 Prompt 结构模板
结构：[产品外观描述+占比] + [场景：背景+光线+构图] + [卖点视觉元素] + [画质]
1. 主体描述：产品名称、颜色、材质、结构细节、占比（60%-80%）、构图位置
2. 场景：背景描述、光线体系、布光方式
3. 卖点视觉元素：每个卖点翻译成具体视觉特效（参考卖点视觉化词典）
4. 画质：8K超高清，电商商品摄影，质感描述，氛围描述
---
