# 商品类型：家居家电
> 拍摄要点、常见卖点、视觉呈现规范

## 拍摄通用要点
- 场景代入：放置在真实家居环境中，营造使用感
- 尺寸对比：搭配参照物（手、水果、书籍）体现大小
- 材质感：陶瓷釉面、玻璃通透、金属拉丝、木质纹理
- 功能可视化：用光效、箭头、对比展现功能
- 细节特写：按钮、接口、出风口、控制面板

## 常见卖点与视觉化
- 强力去污：污渍被光波分解消散特效，前后对比分区展示
- 杀菌：产品释放紫外线光波扩散，细菌图标被消灭
- 清香：产品周围彩色香气波纹扩散，花瓣光点飘浮
- 静音：产品周围声波被吸收消散，安静光圈
- 节能：绿色能量叶子环绕，低功耗数字光效
- 智能控制：手机APP连接光波，WiFi信号波纹
- 大容量：物品填入特效，容量数字光效
- 快速：速度线条，时间数字倒计时光效
- 恒温：温度计光效，暖冷色温对比
- 净化：污染物被过滤消散，蓝色纯净空气波纹

## 合规红线
- 家电参数需与3C认证一致
- 能效标识需真实标注
- 不可宣称医疗杀菌（除非有消毒产品资质）
- 禁用绝对化用语

## 拍摄风格推荐
- 极简北欧风：白灰浅木，柔光，干净
- 自然清新风：绿叶植物，自然光，通透
- 高端商务风：黑金，硬光，质感
- 奶油风：奶白奶黄，柔光，温暖

# 子类：厨房小电
- 场景：厨房台面，搭配食材
- 功能展示：蒸汽、烹饪过程可视化
- 材质感：不锈钢拉丝、黑色磨砂、玻璃壶身
- 细节：控制面板、接口、把手

# 子类：生活电器
- 场景：客厅/卧室环境，营造家居感
- 功能可视化：风量、光线、声波特效
- 静音表现：声波吸收特效
- 智能控制：APP连接光效

# 子类：清洁用品
- 对比展示：前后分区，污渍消散
- 功能特效：紫外线杀菌、香气扩散
- 场景：浴室/厨房真实环境
- 细节：刷头、喷头、把手

# 子类：家具
- 场景代入：完整家居环境，搭配软装
- 材质感：木纹、布艺、皮革、金属拉丝
- 细节：接缝、五金、边角处理
- 尺寸感：参照物对比

# 子类：家纺软装
- 材质感：棉麻纹理、丝绸光泽、毛绒质感
- 垂坠感：自然褶皱，动态飘动
- 场景：床铺/沙发/窗帘真实场景
- 配色：与家居风格协调
