# 风格：极简ins风
- 适用商品：美妆、护肤品、饰品、文具、家居小物、咖啡器具
- 配色：莫兰迪色系（雾粉、灰绿、米白、裸色），低饱和高级感
- 元素：几何形、大理石纹、干花、金属线、留白
- 光线：大平光柔光，均匀无阴影，通透感
- 背景：纯色莫兰迪背景或大理石纹理，干净
- 构图：极简留白，商品居中或三分法，道具克制
- prompt 模板：商品摄影，{product}，极简ins风格，莫兰迪雾粉与米白配色，大理石纹理背景，大平光柔和均匀，无阴影，极简留白构图，干花金属线克制点缀，高级感氛围，低饱和度，8K超高清，ins风精修
- 负面提示：复杂背景，高饱和，强阴影，复古，工业风

# 风格：奶油风
- 适用商品：母婴、甜品零食、护肤、家居软装、礼品
- 配色：奶白、奶油黄、浅咖、奶杏色，温暖柔和
- 元素：奶油质感、波浪边、柔和光斑、毛绒纹理
- 光线：柔和大平光，暖调，无强阴影，绵密感
- 背景：奶白渐变或浅咖纹理，可有波浪边装饰
- 构图：圆润柔和构图，商品居中，温暖包裹感
- prompt 模板：商品摄影，{product}，奶油风格，奶白与奶油黄配色，柔和波浪边装饰，大平光暖调，奶白渐变背景，毛绒奶油质感，圆润柔和构图，温暖包裹氛围，8K超高清，柔和绵密质感
- 负面提示：硬光，冷色调，高对比，工业风，暗黑系

# 风格：轻奢INS
- 适用商品：珠宝首饰、手表、香水、高端美妆、设计师单品
- 配色：香槟金、玫瑰金、雾灰、奶白，金属光泽点缀
- 元素：大理石、丝绒、金属几何、水波纹、柔和光斑
- 光线：侧光 + 轮廓光，金属高光锐利，整体柔和
- 背景：大理石纹理或雾灰渐变，丝绒质感
- 构图：商品居中，金属几何道具搭配，留白
- prompt 模板：商品摄影，{product}，轻奢ins风格，香槟金与雾灰配色，大理石纹理背景，侧光加轮廓光，金属高光锐利，丝绒质感道具，柔和光斑点缀，高级感构图，8K超高清，轻奢精修
- 负面提示：廉价感，杂乱背景，强对比，复古做旧，卡通
