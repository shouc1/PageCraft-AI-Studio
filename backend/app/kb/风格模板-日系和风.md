# 风格：日系和风
- 适用商品：化妆品、护肤品、茶具、和风零食、文具、棉麻服饰
- 配色：米白、浅木、淡粉、抹茶绿、藏青，低饱和柔和色
- 元素：樱花、浮世绘浪花、和纸纹理、麻绳、木质托盘、留白意境
- 光线：柔和漫射光，自然透光，低对比，通透感
- 背景：米白渐变或浅木纹，可有和纸纹理
- 构图：留白构图，商品偏左下，右上方留白，禅意
- prompt 模板：商品摄影，{product}，日系和风风格，米白与浅木配色，樱花花瓣飘浮点缀，和纸纹理背景，柔和漫射自然光，留白意境构图，商品偏左下，禅意氛围，低饱和柔和色调，8K超高清，文艺质感
- 负面提示：高饱和，霓虹色，复杂背景，强对比，赛博风

# 风格：日系治愈
- 适用商品：母婴用品、护肤品、甜点零食、家居小物、文具
- 配色：奶白、浅粉、薄荷绿、鹅黄，马卡龙色系
- 元素：棉花、云朵、柔和光斑、小碎花、手绘感装饰
- 光线：柔和大平光，高调，无强阴影，治愈感
- 背景：纯白或浅粉渐变，可有云朵或小碎花虚化
- 构图：商品居中，柔和光斑环绕，温馨感
- prompt 模板：商品摄影，{product}，日系治愈风格，奶白与浅粉配色，棉花云朵元素点缀，柔和大平光，纯白渐变背景，柔和光斑环绕，高调无强阴影，温馨治愈氛围，马卡龙色系，8K超高清，柔和质感
- 负面提示：硬光，深色背景，高对比，工业风，暗黑系

# 风格：侘寂风
- 适用商品：高端护肤、茶器、香氛、家居摆件、手工艺品
- 配色：宣纸白、枯草褐、墨灰、陶土色，极低饱和
- 元素：枯枝、陶器纹理、宣纸、墨迹、留白、不规则肌理
- 光线：侧光柔和，强调肌理与阴影层次，禅意
- 背景：宣纸纹理或陶土墙面，大面积留白
- 构图：极简留白，商品偏置，不完美之美
- prompt 模板：商品摄影，{product}，侘寂风格，宣纸白与墨灰配色，枯枝陶器点缀，宣纸纹理背景，侧光柔和强调肌理，大面积留白构图，不规则之美，极低饱和度，禅意氛围，8K超高清，艺术质感
- 负面提示：繁华装饰，高饱和，现代感，霓虹色，复杂元素
