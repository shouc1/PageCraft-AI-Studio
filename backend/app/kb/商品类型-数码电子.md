# 商品类型：数码电子
> 拍摄要点、常见卖点、视觉呈现规范

## 拍摄通用要点
- 材质感展现：金属磨砂、玻璃通透、塑料哑光、橡胶质感
- 接口细节：特写展示接口、按键、扬声器孔位
- 屏幕显示：开机状态，UI界面清晰
- 倾斜角度：30-45度展现立体感，避免纯正面呆板
- 光影控制：硬光展现金属高光，柔光展现磨砂质感

## 常见卖点与视觉化
- 降噪：耳机两侧环绕半透明淡蓝色波纹屏蔽声波特效
- 低延迟：右下角淡紫色流光电竞线条光效，游戏手柄轮廓微光
- 防水：产品周围水滴飞溅特效，IPX等级数字微光浮现
- 长续航：悬浮发光电池图标，满格能量条光效
- 快充：闪电状光效环绕接口，充电线末端发光
- 高清音质：金色声波涟漪从产品扩散，音符光点飘浮
- 蓝牙连接：产品与手机之间蓝色信号波纹连接线
- 无线充电：产品底部辐射状能量光圈，充电板发光纹路
- 高刷新率：画面残影拖尾特效，流畅感可视化
- 散热好：气流穿过特效，蓝色冷光散热片

## 合规红线
- 参数真实：所有参数必须与3C认证一致
- 不可夸大："最强""最快""革命性"需有数据支撑
- 5G/WiFi等宣称需有认证
- 电池续航数据需标注测试条件

## 拍摄风格推荐
- 科技未来风：深蓝紫青配色，霓虹光效，赛博朋克
- 高端商务风：黑金银，硬光，倒影反射
- 极简北欧风：白灰浅木，柔光，干净

# 子类：耳机音箱

# 子类：手机平板
- 屏幕展现：开机UI，色彩鲜艳
- 边框细节：金属/塑料材质，厚度对比
- 背面设计：摄像头模组、品牌LOGO
- 持握感：手持角度展示

# 子类：电脑外设
- 键盘：键帽细节，背光光效，倾斜展示
- 鼠标：弧度曲线，RGB灯效
- 功能展示：按键特写，接口细节

# 子类：智能穿戴
- 表盘显示：UI界面清晰，多彩表盘
- 表带质感：硅胶/金属/皮质纹理
- 佩戴场景：手腕贴合，运动/商务场景
- 功能可视化：心率光效，运动数据

# 子类：游戏外设
- RGB灯效：多彩背光，电竞氛围
- 机械质感：键轴特写，金属面板
- 场景：电竞房暗环境，霓虹光
- 速度感：动态线条，速度光轨
