# 淘宝天猫主图规范
- 尺寸：800×800 像素（最低），推荐 1200×1200 或 1500×1500
- 背景：白底为主（第一张必须白底），后续可场景图
- 文字占比：不超过图片面积 20%
- 主体：商品占比 60%~80%，居中或偏左
- 水印：不支持，平台会自动添加
- 格式：JPG / PNG，文件大小 ≤ 3MB
- 数量：5 张主图，第一张最关键

# 京东主图规范
- 尺寸：800×800 像素（最低），推荐 1200×1200
- 背景：第一张必须白底（RGB 255,255,255）
- 文字：不允许促销文案，仅可放品牌 LOGO
- 主体：商品占比 ≥ 70%，居中
- 格式：JPG / PNG，≤ 1MB
- 数量：6 张主图

---

# 拼多多主图规范
- 尺寸：750×352 像素（轮播图第一张），或 750×750
- 背景：无强制白底要求，允许场景图
- 文字：允许促销文案，但不可有"最""第一"等极限词
- 主体：商品占比 ≥ 50%
- 格式：JPG / PNG，≤ 1MB
- 数量：10 张轮播图

# 抖音电商主图规范
- 尺寸：1080×1080 像素（推荐），最低 600×600
- 背景：无强制要求，场景图效果更好
- 文字：允许，但不建议过多，短视频封面感
- 主体：商品占比 40%~60%，可有人物使用场景
- 格式：JPG / PNG，≤ 5MB
- 数量：5 张主图

---

# 电商主图通用构图规范
- 三分法构图：商品放在画面 1/3 或 2/3 交叉点
- 居中构图：商品居中，适合白底图
- 对角线构图：商品倾斜 30~45 度，增加动感
- 留白：四周留 10%~15% 空间，避免满铺
- 景深：浅景深虚化背景，突出商品
- 光影：柔和均匀，避免硬阴影

---

# 电商主图配色规范
- 白底图：纯白背景 RGB(255,255,255)，商品为视觉中心
- 场景图：背景与商品色系互补或同色系延伸
- 促销图：红黄暖色调激发购买欲，品牌色点缀
- 高端图：黑灰金配色，低饱和度，高级感
- 清新图：蓝绿冷色调，高明度，通透感
