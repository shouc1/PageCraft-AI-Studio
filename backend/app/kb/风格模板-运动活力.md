# 风格：运动活力
- 适用商品：运动鞋、运动服饰、健身器材、能量饮料、户外装备
- 配色：荧光橙、电光绿、活力黄、深蓝撞色
- 元素：动态线条、速度光轨、能量爆发、运动轨迹、汗珠飞溅
- 光线：硬朗侧光 + 轮廓逆光，高对比，突显材质与动感
- 背景：深色渐变（深蓝→黑）或运动场虚化，可有速度线纹理
- 构图：商品倾斜15-30度，动感构图，留白体现速度方向
- prompt 模板：商品摄影，{product}，运动活力风格，荧光橙与电光绿配色，动态速度光轨线条，深蓝渐变背景，硬朗侧光加轮廓逆光，能量爆发特效，汗珠飞溅，倾斜动感构图，高对比度，商业精修，8K超高清
- 负面提示：静态感，柔和光线，低饱和度，复古，暗淡，平庸构图

# 风格：运动竞技专业
- 适用商品：篮球鞋、跑步装备、球拍、专业护具、运动手表
- 配色：黑红、黑金、深蓝银，专业感强
- 元素：数据光效、轨迹线、肌肉纹理、力量爆发光圈

- 背景：纯黑或赛场虚化，可有数据网格暗纹
- 构图：商品居中悬浮，力量感环绕特效
- prompt 模板：商品摄影，{product}，专业竞技风格，黑红配色，力量爆发光圈环绕，数据光效轨迹线，纯黑背景，戏剧性硬光，体积光束，商品悬浮居中，专业运动质感，8K超高清，商业精修
- 负面提示：休闲感，柔和色调，杂乱背景，玩具感

# 风格：户外探险
- 适用商品：登山装备、露营用品、越野车配件、户外手表、旅行箱包
- 配色：大地色系（卡其、军绿、岩石灰）+ 品牌色点缀
- 元素：山峦剪影、岩石纹理、阳光穿透云层、尘土飞扬
- 光线：黄金时刻侧逆光，暖色调，大气透视
- 背景：户外场景虚化（山脉/森林/沙漠），层次丰富
- 构图：商品居中或偏右，左留白显场景
- prompt 模板：商品摄影，{product}，户外探险风格，卡其军绿配色，山峦剪影背景，黄金时刻侧逆光，阳光穿透云层光束，岩石纹理质感，尘土飞扬氛围，大气透视层次，8K超高清，商业精修
- 负面提示：室内感，都市背景，冷色调，柔光，平淡
