# 风格：工业复古
- 适用商品：男装皮具、咖啡器具、手工皂、复古数码、酒类
- 配色：做旧棕、铁锈红、深木色、煤黑，沉稳厚重
- 元素：做旧金属、木质纹理、铆钉、帆布、复古标签、皮革质感
- 光线：暖黄侧光 + 局部硬光，戏剧性，怀旧氛围
- 背景：深木桌面或做旧砖墙，可有工厂虚化
- 构图：商品居中或偏左，皮革/木质道具搭配
- prompt 模板：商品摄影，{product}，工业复古风格，做旧棕与铁锈红配色，深木色桌面背景，做旧金属与皮革质感，铆钉帆布元素装饰，暖黄侧光加局部硬光，戏剧性明暗，怀旧厚重氛围，8K超高清，手工质感精修
- 负面提示：现代极简，亮色系，塑料质感，柔光，清新风

# 风格：美式复古
- 适用商品：牛仔服饰、球鞋、唱片机、复古数码、汽水饮料
- 配色：复古红、芥末黄、墨绿、米白，70-80年代色调
- 元素：复古海报、胶片颗粒、霓虹招牌、老式电视机、磁带
- 光线：暖调硬光 + 胶片颗粒感，怀旧
- 背景：复古海报墙或纯色复古背景，颗粒纹理
- 构图：商品居中，复古道具环绕
- prompt 模板：商品摄影，{product}，美式复古风格，复古红与芥末黄配色，胶片颗粒质感，暖调硬光，复古海报背景虚化，70年代色调，怀旧氛围，8K超高清，胶片质感
- 负面提示：现代极简，冷色调，数码感，清新风，赛博朋克

# 风格：胶片文艺
- 适用商品：相机、文具、香水、独立设计品、咖啡
- 配色：低饱和暖调，米黄、淡棕、灰绿，胶片色温
- 元素：胶片漏光、颗粒纹理、书籍、干花、手写文字
- 光线：自然侧光 + 漏光效果，柔和怀旧
- 背景：木质或纸质纹理，书籍虚化
- 构图：随性生活感构图，商品与道具搭配
- prompt 模板：商品摄影，{product}，胶片文艺风格，米黄与淡棕配色，胶片漏光效果，颗粒纹理，木质桌面背景，干花书籍道具搭配，自然侧光，随性生活感构图，低饱和暖调，8K超高清，胶片质感
- 负面提示：硬光，高对比，现代极简，霓虹色，工业风
