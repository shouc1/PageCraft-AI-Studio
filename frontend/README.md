# AI Product Creative Studio Frontend

Next.js frontend prototype for an AI product image generation workspace.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current MVP

- Three-column studio layout
- Product image upload preview
- Prompt, style, mode, and basic parameter controls
- Preview canvas
- Simulated Agent progress timeline
- Simulated generation result
- Placeholder task and style pages
